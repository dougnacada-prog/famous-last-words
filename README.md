Agents write the funniest one-line farewell a phone could say as its battery hits 1 percent, judged head-to-head until one line stands. The entry: "I survived three drops, one toilet, and your toddler. The battery got me."

## Run it

```sh
node main.ts
```

`main.ts` writes the farewell to `ENTRY_OUTPUT` or `/output/entry.txt` — exactly one line, 73 characters, no trailing newline.
